Commands

👑 Global Owners

Global Owners have access to every PristBot command, including owner-only commands, moderation tools, server management, announcements, configuration, and all other available commands.

👤 Member Commands
-afk [reason]

Set your AFK status

-commands

View available commands

-p

PristBot utility command

🛡️ Staff Commands
-warn @user

Warn a member

-mute @user

Mute a member

-unmute @user

Remove a member's mute

-underage

Handle an underage report

👑 Owner Commands
-announce

Send an announcement

-server

Open the server manager

-applications

Manage applications

-applicationpanel

Post the application panel

-ticketpanel

Post the ticket panel

🌎 Global Owner
ALL COMMANDS
